# Torch-eCpG macOS arm64 CPU Bundle

This artifact is a macOS arm64 CPU-first bundle. It includes a Python runtime
environment, the installed `tecpg` package, runtime dependencies, a launcher,
smoke test, license materials, and a SHA256 checksum generated by the packaging
workflow.

Run the CLI from the unpacked bundle with:

```sh
launchers/tecpg --help
launchers/tecpg data --help
launchers/tecpg run mlr --help
```

This bundle does not include GPU/CUDA validation and must not be described as a
GPU-enabled downloadable artifact. GPU/CUDA validation remains a separate
workflow and release decision.

The workflow smoke test validates the unpacked launcher help commands only. It
does not prove release readiness, scientific correctness, Windows packaging,
signing, notarization, quarantine behavior, or CUDA/GPU support.
